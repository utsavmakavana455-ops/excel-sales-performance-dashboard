# 📊 Excel Sales Performance Dashboard

An interactive **Sales Performance Dashboard built in Microsoft Excel** to analyze sales performance and provide clear business insights.

## 🔍 Project Overview

This dashboard transforms sales data into an interactive and easy-to-understand business report using Excel's data analysis and visualization features.

## 🛠️ Tools & Features

* Microsoft Excel
* Excel Tables
* PivotTables
* PivotCharts
* Slicers
* KPI Cards
* Data Analysis
* Business Insights

## 📈 Dashboard

The dashboard includes:

* Total Sales
* Total Orders
* Total Units Sold
* Completion Rate
* Average Order Value
* Monthly Sales Trend
* Sales by Category
* Sales by City
* Top Products
* Interactive filters for Category, City, Status, Payment Method, and Gender
